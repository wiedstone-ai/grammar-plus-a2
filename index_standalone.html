Cara Deploy Google Apps Script (1 Menit):

  1. Buka tautan Google Spreadsheet di atas.
  2. Klik menu Extensions (Ekstensi) → Apps Script.
  3. Buka file google_apps_script.js yang disertakan di website ini, salin seluruh kodenya, dan tempel ke editor Apps Script.
  4. Klik Deploy (Terapkan) → New deployment (Penerapan baru) → Pilih jenis Web app.
  5. Set Execute as: Me dan Who has access: Anyone. Lalu salin URL Web App yang dihasilkan ke kotak isian di atas.
